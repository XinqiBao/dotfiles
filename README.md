# dotfiles

Personal configuration for shell, editor, terminal, and development tools. Files follow their usual locations under the home directory, including `.bashrc`, `.tmux.conf`, `.vimrc`, and `.config/`.

Review the relevant files before applying them to another machine. Copy or merge the settings you need into the tool's configuration, then check that the tool behaves as expected. Some settings depend on installed plugins, commands, or platform-specific features.
